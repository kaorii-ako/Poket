Poket web UI

Four directions for the page the ESP32-S3 serves over its own Wi-Fi access point. Same features in all four: upload, library, transport, and the OLED theme picker.

The 128 × 64 preview in every prototype is drawn by the firmware's own drawing code and glyph bytes, at an integer zoom — one panel pixel is exactly N × N screen pixels, never resampled.

Direction 1 J-Card Ink on card stock. Spine, ruled tracklist, the upload zone as a blank Side B. Accent reseeds from the theme you pick. Direction 2 Bench instrument Gunmetal chassis, keycaps with real travel, a knurled knob, one orange commit key, and an amber readout. Direction 3 Fab drawing The board documenting itself. Silkscreen on solder mask, reference designators on every control, title block in the corner. Direction 4 · control Plain The canon settings page. System type, grouped rows, one accent, light and dark. What the other three have to beat.
Themes
Minimal · Anime · Terminal · Cassette · Brutalist · Y2K, plus custom uploads
Panel
SSD1306, 128 × 64, 1 bit — no greys, so every theme is built out of dither and 1 px rules
Shared
../lib/oled.js (port of ui/gfx.c + the six themes), ../lib/fonts.js (generated by tools/mkfont.py --format js), ../lib/data.js
Serving
Open any file directly, or python3 -m http.server in this folder — they are ES modules, so file:// needs a server in some browsers
